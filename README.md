# Métodos Numéricos para EDO y EDP

Apuntes del curso sobre métodos numéricos para ecuaciones diferenciales: problemas de valor inicial, métodos de Runge–Kutta, estabilidad, condiciones de contorno, problemas de valores de frontera y una introducción a ecuaciones en derivadas parciales.

## Contenido

### Parte I — Problemas de Valor Inicial (marcha paso a paso)

1. **[Problemas de Valor Inicial (PVI)](01-PVI.md)** — Euler hacia adelante/atrás, sistemas de EDO, introducción al MDF
2. **[Métodos de Runge–Kutta](02-RungeKutta.md)** — RK2, RK4, RK implícitos
3. **[Análisis de Estabilidad](03-Estabilidad.md)** — estabilidad de Euler, ecuaciones rígidas

### Parte II — Problemas de Valores de Frontera (resolución global)

4. **[Condiciones de Contorno](04-CondicionesContorno.md)** — Dirichlet, Neumann, Robin y su tratamiento numérico
5. **[Problemas de Valores de Frontera (PVF)](05-PVF.md)** — método del disparo, MDF para PVF
6. **[Problemas de Autovalores](06-Autovalores.md)** — método del disparo para autovalores, partícula en una caja

### Parte III — Ecuaciones en Derivadas Parciales (los dos mundos combinados)

7. **[Ecuaciones en Derivadas Parciales (EDP)](07-EDP.md)** — clasificación elípticas / parabólicas / hiperbólicas
